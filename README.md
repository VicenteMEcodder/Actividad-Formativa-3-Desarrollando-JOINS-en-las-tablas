## 📖 Actividad actual – Semana 4

**Experiencia 2: Desarrollando JOINS en las tablas**

Actividad formativa basada en el caso de Conciertos Chile S.A., orientada al desarrollo de consultas SQL mediante JOINS, funciones de una fila, funciones de grupo y expresiones condicionales.

## 🎯 Propósito

Construir consultas SQL que permitan relacionar información de múltiples tablas, aplicar filtros, realizar agrupaciones y generar reportes según los requerimientos establecidos.

## 🛠️ Herramientas utilizadas

- Oracle SQL Developer
- Oracle Database
- SQL
- Git y GitHub

## 📂 Archivos Semana 4

- `README.md` – Documentación de la actividad.

## 📊 Informes desarrollados

**Caso 1: Listado de Trabajadores**  
Consulta de trabajadores con sueldo base entre $650.000 y $3.000.000, utilizando JOIN, funciones de formato y ordenamiento.

**Caso 2: Listado de Cajeros**  
Reporte de tickets vendidos, montos de ventas y comisiones, utilizando JOIN, COUNT, SUM, GROUP BY y HAVING.

**Caso 3: Listado de Bonificaciones**  
Consulta de trabajadores con cálculo de antigüedad, cargas familiares, bono FONASA y bonificación por años de servicio.
